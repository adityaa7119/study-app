## 🌟 Key Features

- **Concept to Code Simulator** (`/simulator`): Interactive physics & math simulations (Projectile, Damped Oscillator, Fourier Waveform, RLC Resonance) with synchronized real-time Python (SciPy) and MATLAB (ode45) code.
- **Placement & Career Hub** (`/placement`): Campus recruiter cutoffs (Google, Microsoft, Amazon, Qualcomm, Barclays, TCS), solved technical OA question bank, instant ATS resume keyword scorer, and application pipeline tracker.
- **Study Shorts** (`/shorts`): Curated educational STEM video shorts with interactive quizzes, formulas, and 1-click YouTube video linking.
- **Project Lab** (`/projects`): Branch & year-based mini-project suggester with step-by-step build plans, datasets, starter code, and STAR resume bullets.
- **Focus Shield** (`/focus`): Deep work Pomodoro timer with custom study time controllers (1 to 240 mins), range sliders, steppers, and manual subject typing.
- **Mobile-First Responsive Design**: Tailored layout for both smartphone touchscreens and desktop monitors.
